# Changelog

## Unreleased

### Added

- JSON-LD `BlogPosting` dan FAQ otomatis dari konten artikel yang terlihat.
- Generator Open Graph artikel 1200x630 dengan cache dan metadata social share lengkap.
- Submit sitemap otomatis melalui Google Search Console Sitemaps API.
- Dokumentasi operasional SEO Tech.

### Changed

- FAQ homepage dan schema memakai satu sumber konfigurasi.
- Sitemap index memuat `lastmod`; child sitemap kini menampilkan `changefreq` dengan benar.
- URL publik dengan trailing slash dan parameter tracking dinormalisasi melalui redirect 301.
